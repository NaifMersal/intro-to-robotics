# Intro to Robotics

**From Water Pipes to Computer Logic**

A hands-on robotics course covering electronics fundamentals, microcontrollers, sensors, and autonomous robot design. Built with Quarto and deployed as an interactive website with slides, simulations, and a final quiz.

🔗 **Course Site:** <https://naifmersal.github.io/intro-to-robotics/>

## Sessions

| # | Topic | Description |
|---|-------|-------------|
| 1 | Circuits Basics | Voltage, current, resistance — the water-pipe analogy |
| 2 | Movement + Problem Patterns | Robot locomotion and problem identification |
| 3 | Building the Smart Radar | Ultrasonic sensor + servo motor |
| 4 | The Autonomous Explorer | Obstacle-avoiding robot |
| 5 | Code Mastery Recap | Core concepts review |
| 🧪 | Final Quiz | 11-question interactive challenge |
| 🗺️ | Robotics Adventure Roadmap | Next steps: PID, ESP32, AI vision, and more |

## Interactive Simulations

- **Water Circuit Sim** — visualize voltage, current, and resistance as water flow
- **Water Resistors Sim** — series & parallel resistor networks

## Tech Stack

- [Quarto](https://quarto.org/) (Reveal.js slides + website)
- [Wokwi](https://wokwi.com/) (Arduino simulations)
- Vanilla HTML/CSS/JS (interactive sims)
