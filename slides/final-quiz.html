Question 2: Wokwi Debugging 🔌

  // Setup runs once

  digitalWrite(13, HIGH); // Turn LED on
}

Why is the LED not turning on?

  • We used HIGH instead of ON or 1 which causes a compilation crash.
  • Arduino pins can only be turned on by using analogWrite(13, 255);.
  • Wokwi doesn’t support Pin 13 because it is reserved for the USB programmer.
